# Euronest Apartamentos — página web

Next.js (App Router) + TypeScript + Tailwind CSS + Supabase.

## Puesta en marcha

1. `npm ci`
2. Copia `.env.example` a `.env.local` y rellena las claves de Supabase.
3. `npm run dev` y abre http://localhost:3000

## Comandos

- `npm run dev` — servidor local
- `npm run build` — build de producción
- `npm run lint` — linter

Las instrucciones de trabajo del proyecto están en `CLAUDE.md`.
